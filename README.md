## ⚙️ How we build

- **AI 에이전트 팀 개발**: 팀장 에이전트가 작업을 나누고, 팀원 에이전트가 구현하며, 팀장이 독립 검증한 뒤 병합합니다.
- **문서가 정본**: 요구사항정의서 → IA · ERD · API 명세 → Figma 화면설계 → 코드 순으로 추적합니다.
- **게이트로 막는 품질**: 타입 · 린트 · 단위/통합 테스트 · E2E · 권한 매트릭스 · 원장 정합성 검사를 통과해야 배포합니다.
- **발주사 인계 표준**: 납품할 때 클린 소스, 기능검수표, API 문서(Swagger), 운영 매뉴얼을 함께 넘깁니다.
